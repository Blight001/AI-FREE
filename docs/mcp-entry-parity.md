# 外部 MCP 与 AI 控制侧栏一致性

外部入口包括本机 `/mcp/v1` 和转发到同一网关的 stdio。内置入口是「AI 控制」侧栏提交给模型的 `localInteraction` 工具。自动化卡片和 HeySure 设备调用也是共享契约的消费者。

## 共同契约

- 相同授权、浏览器能力、目标文档和等效输入应得到相同的操作、业务结果、错误码、重试语义及副作用。入口负责授权上下文、目标选择、取消信号、传输和展示。
- 工具目录、模型说明、观察与执行须使用同一能力规则。权限或内核能力有差异时，应记录执行资格、拒绝原因和恢复方式。意图筛选只影响提交给模型的工具目录。
- 页面动作须绑定实际文档。文件上传须验证工作区路径和字节，并核对文件选择 ID。可信输入回执与网页业务回执分别记录。已发送且结果未知的操作应先核验，再决定是否重试。
- 评估同一模型时应记录模型版本、工具目录、提示、权限、视口和网站状态。用确定性双入口用例隔离模型决策差异，再分别测量真实客户端的提交次数、耗时、站点结果和误操作。

## 执行路径

| 调用方 | 实现和边界 |
| --- | --- |
| 外部 MCP | [网关](../src/app/backend/services/browser-automation-external-gateway.js)校验授权和路由。对共享页面工具，[页面适配](../src/app/backend/services/external-browser-page-routing.js)从活动标签取得文档令牌，进入原生服务的统一绑定执行。部分页面操作为缺少令牌的旧内核保留外部兼容路径。`save_session` 要求有效文档令牌和支持该命令的内核。HTTP 请求断开时向执行层传递取消信号。 |
| AI 控制 | [侧栏路由](../src/app/backend/features/ai-chat/chat-tool-executor.js)按当前轮次和窗口选择确定目标，[目标校验](../src/app/backend/features/ai-chat/chat-browser-target.js)为页面操作绑定文档。侧栏负责上传交互、产物卡片、工具时间线及用户插话。 |
| 自动化卡片 | [卡片路由](../src/app/backend/services/automation-card-mcp-router.js)查询已注册工具，经共享桥接和原生服务分派。保存的卡片保持原有参数和步骤格式。卡片允许跨页和改变窗口，仍有自己的目标生命周期。 |
| HeySure | 以外部目录为输入，转换工具名并复用外部分派。设备适配负责 `file_ref` 的下载物化与结果上传，相关授权和临时文件生命周期由设备调用拥有。 |

## 全工具对照

Chromium 已连接、本机账号工具可用且侧栏有环境配置意图时，两个入口各有 **15 项**，同名工具的输入 schema 已用集成测试比对。浏览器路由字段的说明随入口调整。开发模式首页 MCP 目录展示总工具集。

| 工具 | 已对齐的行为 | 差异与后续验收 |
| --- | --- | --- |
| `browser_control` | 接管、状态、释放共用服务。无连接时两个入口均提供总览。 | 外部默认跟随活动栏目，侧栏按本轮已选浏览器路由，接管时沿用已有文档绑定。补测两个窗口同时在线、显式选中窗口离线及切换后的重新选择。 |
| `browser_tab` | 标签命令共用 Chromium 实现。 | 外部标签结果兼容 `pageToken`，侧栏从模型结果移除它。统一公开字段前先核对外部消费者。 |
| `browser_observe` | 观察和上传共用内核文件控件判断。可识别透明 `input` 及关联隐藏 `input` 的可点击 `label`。引用绑定文档，并分别归外部入口和侧栏所有。 | 同一入口的多个客户端或轮次仍共享该入口的引用集合。细化所有权时覆盖交错观察、同 URL 刷新及陈旧引用拒绝。 |
| `browser_action` | 单步动作与业务探针使用统一目标解析，文档校验覆盖诊断及可信输入。保留 `actionExecuted` 和业务探针回执。 | 软件界面动作依入口授权和资源条件执行。新增动作时同时核对观察出的目标、执行失败码及未知结果处理。 |
| `browser_wait` | 固定时长和同页条件等待共享文档绑定。无目标的 `url_matches` 可观察导航。 | 验证等待取消、换文档和 URL 条件并发，尤其是超时与目标变更先后发生时的反馈。 |
| `browser_screenshot` | 共享页面截图和文档绑定。 | 外部传 MCP 图像块，侧栏生成模型图像输入与时间线。软件界面截图的资格由入口确定。 |
| `browser_file` | `download_element`、`upload` 和 `save_session` 共用文档绑定。会话导出在内核读取 Storage 和 Cookie 后均验证文档，成功时只在工作区保存内容，工具返回文件元数据。原生下载支持页面 HTTP(S) 链接及图片、媒体。临时文件保留内核实际解析出的资源后缀，以供 Chromium 下载安全策略判断。省略 `filename` 时使用资源文件名，政策拒绝的下载返回失败。两端直接上传工作区文件，校验文件路径、字节、文档和文件选择回执。 | 侧栏绑定路径仍拒绝 `download`、`info`、`upload_to_server`。后续对齐分别核对直接下载的网络与会话边界、工作区元信息和 HeySure 远端上传资格。 |
| `browser_media` | 共享发现和元素下载服务。 | 补测音频、视频及内核原生下载失败的不同形态，核对 `downloadable` 与实际可下载能力。 |
| `manage_card` | 共享卡片库及执行器。侧栏拥有和外部相同的卡片接管检查。 | 补测两端创建、版本回读和闭环执行。核对既有卡片、递归拦截及卡片内部调用的目标生命周期。 |
| `browser_page_batch` | 两个入口共用短时同页串行执行器。每步复用页面动作和等待的校验。 | 侧栏插话中断旧计划，HTTP 断连传入取消信号。并发测试应同时记录已执行、未尝试与结果未知的步骤。 |
| `browser_workflow` | 两个入口共用既有工作流、诊断和报告。停止或断连后，已派发步骤在安全边界结束，后续步骤暂停并释放接管。 | 工作流可跨页，按现有流程规则核对项目身份。补测多个客户端尝试暂停、恢复同一运行。 |
| `windows_tab` | 共用软件栏目工具。 | 两端各自同步窗口选择状态。双入口逐动作验收应覆盖打开、关闭、焦点和离线目标。 |
| `browser_environment` | 共享环境服务。外部目录常驻，侧栏按意图注入。 | 用隔离 Profile 覆盖增量修改、脱敏读回、重启和未改字段保留。 |
| `account_manage` | 共享账号工具、脱敏、本机删除确认和批量导入。两种入口均传递调用取消信号。批量导入直接消费转换命令输出，回执只包含计数或结构化错误。 | 双入口测试用不同来源格式导入同一账号库，并核对失败回执和凭据隔离。 |
| `run_command` | 共享进程执行。侧栏流式展示输出，外部等待工具结果。 | 比对退出码、截断、时限、进程树回收及 HTTP 断连和侧栏停止。 |

## 回归与维护

- [双入口集成测试](../test/integration/mcp-entry-parity.test.js)比对全部目录和参数，并验证总览、标签、观察引用隔离、媒体、等待、截图、接管、PNG 下载上传、会话导出及目标切换拒绝、卡片读取和接管限制、批处理、工作流停止、账号脱敏和命令结果。
- [真实 Chromium 文件验收](../test/helpers/flows/chromium-mcp-file-parity.js)从外部网关和侧栏后端分别完成链接下载、关联加号上传、可信提交、业务探针核验和截图。服务端核对两次提交各自只发生一次，收件 SHA-256 与下载的 PNG 一致。命令为 `npm run accept:chromium-phase3 -- --page-binding-only`。`npm run accept:chromium-phase3 -- --session-export-only` 单独验证两端导出的工作区文件、Cookie/Storage 和脱敏回执。
- 真实 Electron 侧栏回归覆盖工具调用、模型图像输入、上传交互和重开恢复。真实 Nova Reel 的模型成绩单独记录。涉及 HTTP、stdio 或打包资源时，验收对应入口。
- 内外入口共用 `browser_file` 的说明和原生回执。双入口文件回归覆盖站点依赖可信下载点击的情况。直接保存资源后，浏览器仍可选择文件，页面会拒收。点击下载入口后，校验新落盘 PNG 的字节、页面收件回执及最终提交。
- 改动文件或动作契约时应覆盖文档切换、陈旧引用、文件被替换、断开和回执丢失。重试对照以网页提交次数和实际状态为准。更新共享行为时同步检查老卡片、HeySure 兼容参数、审计脱敏及失败恢复。

统一校验会影响两端同时使用时的活动标签、指针和接管争用。入口级引用隔离已有回归，进一步按客户端隔离需要明确观察和文件选择的生命周期。共享能力和错误规则可以减少工具提示、目录、路由和执行逻辑重复维护。新增例外应列出执行资格、失败回执和对照用例，兼容分支应写明移除条件。
